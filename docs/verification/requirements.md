numbers of the same prefix separated by `,`, `/`, `and` or `or`. A range after a cited number
(`1050 to 1054`, `0400-0419`, also with `–`, `…` or `...`) cites every ID from its first to its last number
within the same prefix; IDs in the range that no specification defines are ignored. A dash marks
a range only when the last number follows it directly (`9370 - 9372` is no range). A range of
more than 200 IDs is not expanded: only its first number counts as cited.
