# ADR 0002 — 独立的私有共享基础库

Status: accepted, 2026-10-25.

RustSys、RustSTA、Studio 原来维护相同或近似的共享实现。第二阶段将实现归属移到
lab-emi/RustEDA-Common。负责人明确选择私有可见性；迁移后的消费者要求授权 Git 访问。
现有公开仓库的 main 不在本次迁移中修改。

## 决定

- 四个基础库作为固定 Git revision 依赖，不保留消费者内的实现副本。
- 公共命令实现位于 rusteda-cli-common。各产品保留原 rusteda-cli 包和 rusteda
  可执行文件，薄适配器传入产品版本，不改变历史记录或 --version 的含义。
- 所有消费者的四个库和公共 CLI 必须来自同一个完整提交号，Cargo.lock 也必须匹配。
- 共享源码和其原有测试、合成夹具留在共享库；产品保留引擎及 CLI 回归测试。
- 需求覆盖检查通过 Cargo metadata 定位共享源码，避免迁移后因目录变化漏掉覆盖。
- root 的 shared 检查验证唯一来源、源文件哈希及所有消费者版本，拒绝重新引入本地副本。

第三方依赖依然使用已批准的固定版本。唯一新增的 Git 来源是这个第一方仓库；
消费者的依赖源白名单相应增加这一项，不放宽第三方许可或来源检查。

## 隐私与验证

共享库自己的 CI 在私有仓库运行。完整跨仓 CI 应在私有集成环境运行，不给公开仓库的
工作流注入私有源码读取密钥。当前阶段用受限本地运行验证消费者；后续联合 CI 沿用这一边界。

代码归属迁移不等于新的 EDA 算法验证结论。四个基础库实施代码保持字节一致；
另验证产品 CLI 的版本、历史、双 PDK 导入/导出和错误行为。
