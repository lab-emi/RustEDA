## 2026-10-23 — Independent GUI framework selection

- Recommendation for a Linux-first native RustLane workbench: egui/eframe/egui_extras/egui-wgpu `=0.37.0`, egui_tiles `=0.18.0`, wgpu `=30.0.1`. Report and evidence: `docs/research/gui-frameworks/`. Production GUI is not implemented; root Cargo.toml/Cargo.lock/core and sibling engines are unchanged.
- Existing RustEDA-Studio uses gpui `=0.2.2`. GPUI Kit `0.8.0` instead pins gpui-pre `=0.3.9` and has an optional GPUI Fast backend. Kit handles its internal version alignment, but its UI types cannot be mixed with gpui 0.2.2. Do not assume existing Studio widgets can be shared unchanged.
- egui_dock `0.21.1` requires egui `^0.36`; it is not type-compatible with the chosen 0.37 cohort. egui_tiles `0.18.0` requires `^0.37.0`. All these pre-1.0 APIs require explicit release/lockfile alignment.

Do not generalize this metadata to all forks; qualify an exact backend/version if reconsidering GPUI Kit.
