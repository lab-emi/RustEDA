# 独立审查材料与尚未获批的事项

本轮收尾提供可复现技术证据，不代替法务、晶圆厂或独立工程师签字。
原始声明和负责人决定分别保存在 `original-status-2026-10-25.md` 与
`owner-decisions-2026-10-25.md`。当前执行结果见 `STATUS.md`。

| 审查项 | 已整理的材料 | 仍需确认 |
| --- | --- | --- |
| 洁净室方法 | 固定参考可执行文件；公开命令行输出；新的电阻扫描、SPICE 网表和原始回执；实现未读取参考工具源码 | 独立审查此前会话及实验记录；迁移前被删除的原始数据无法补作证明 |
| 第三方 RTL 归属 | RustROAD `fixtures/designs/rtl/PROVENANCE.md`；SERV 原有 ISC 声明及 `serv_compdec.v` 的 Apache-2.0 声明、许可证和通知 | 独立核对来源链及再分发要求 |
| 规则 deck 与 PDK | 工具/PDK 文件及目录 SHA-256、固定 OCI 镜像、只调用外部 deck 的回执；版本库未发现跟踪的 `.drc` / `.lydrc` / `.lvs` deck 文件 | 独立审查是否有不当摘录或许可问题；本轮文件清单不构成法律结论 |
| 电源轨直接接反相器输入的常量实现 | 现有流程和原报告 §4.3；现有 DRC/LVS 不能证明 ESD 或可靠性 | 由库/PDK负责人确认是否允许；不能据此宣称可流片 |
| DRC/LVS/天线与时序结果 | 全流程门禁、负控制、重建确定性、制品绑定；MPW 的原始偏差和三条件证据单列 | 独立人工复跑，必要时用其他签核工具与晶圆厂提取器核验 |
| 新的时钟树配置 | mult/regfile 的 SKY130 叶节点扇出上限从 8 降到 4；输入 SDC、周期与验收阈值保持原值；配置由工具重新生成并冻结 | 核对单元数、面积、时钟负载与 setup/hold 结果；这是两个设计的物理配置改进，不是对提取器普适精度的证明 |
| hold 负控制适用性 | dense/GF180 删除延迟插入后仍满足 hold；保留双引擎、三角的实际测值，并要求额外的 2 ns hold-uncertainty 坏样本被两工具拒绝 | 复核“有效坏样本”与“移除后仍正确的电路”的区别；真实漏检和不完整检查仍会使门禁失败 |
| SERV 未使用输入、顶层金属天线处理 | 保留原失败与预算边界，未移除端口、未放宽 LVS 或天线门限 | 负责人裁定未使用端口策略；后续规模阶段解决布局布线与库支持 |

以下边界保持不变：密度单列，未完成金属/FEOL填充；IR/EM、SI、OCV/AOCV、
CPPR、多模式、pad ring 和 seal ring 均未获本轮验证。精度结论限于列出的设计、
PDK、角、线模型和工具版本，不能外推为工业规模或晶圆厂签核。

原报告所称“共享文件变化需要跨仓维护”和“禁止点名外部工具”的问题也已核对：
共享基础库已在上一阶段集中到私有 RustEDA-Common；当前 RustSTA 的
`CONTRIBUTING.md` Rule 8.4 明确允许记录固定版本工具的黑盒比较。
这种政策允许不免除独立验证，也不允许阅读、移植或比较参考工具的源码。
